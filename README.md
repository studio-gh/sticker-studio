# Sticker Studio V11 · Shapes + Explore

This build restores a dedicated Add a shape toolkit and makes Explore useful as a starting point rather than a passive gallery.

## What's new
- Add circle, square, rounded rectangle, triangle, star, and speech bubble as editable layers.
- Shape layers support position, scale, rotation, opacity, and color controls.
- Shapes are included in transparent PNG export.
- Explore has additional sticker ideas, a Shapes category, clearer guidance, and a Remix action that opens a customizable text layer in the editor.
- Sticker previews constrain long text so cards don't crop phrases awkwardly.
- Home shows a broader set of starter ideas.

## Publish
Replace the current GitHub Pages files with the contents of this ZIP. `index.html` is at the ZIP root.

This remains a client-side prototype using browser local storage. Verify touch interactions and export on target mobile devices before commercial release.
